# Cricket Player Management System

## Description

This is a simple JSP-based web application developed for the Cricket domain.

The application displays information about cricket players and their roles, teams, and runs.

## Technologies Used

- Java
- JSP (JavaServer Pages)
- HTML
- CSS
- Apache Tomcat

## Features

- Cricket home page
- View cricket players
- Display player information in a table
- Simple and user-friendly interface

## Project Structure

CricketJSP/
│
├── index.jsp
├── players.jsp
├── style.css
└── README.md

## How to Run

1. Install Apache Tomcat.
2. Copy the `CricketJSP` folder into the Tomcat `webapps` folder.
3. Start Tomcat using `startup.bat`.
4. Open the following URL:

http://localhost:8080/CricketJSP/
